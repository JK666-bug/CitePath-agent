# My Courses

Use `my_courses()` for questions about how many courses the student has, their course names, deadlines, uploaded lecture materials, whether a plan exists, chapter counts, or completed and remaining tasks.

Answer from the returned course data. Keep course facts separate from lecture content: do not use selected PDFs to infer the student's course list or progress. If a value is missing, say it is not set or not available instead of guessing. Answer in the student's language and do not expose internal course IDs unless they ask.
