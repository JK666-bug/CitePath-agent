## 可重复执行的工具

从仓库根目录、使用完整 Python 运行环境：

```powershell
python tools/sql_storage_smoke.py --run
python tools/storage_http_smoke.py --run
```

默认不带 `--run` 时不创建数据。显式运行会创建新的 `citepath_it_...` 账户和专用课程，保留数据；HTTP 检查使用本机 8018 端口并只重启/停止自己创建的 API 进程。默认报告位于 `backend/logs`，可用 `--output` 指定保护目录外的输出文件。依赖、服务和模型缓存需可访问。没有删除已有课程、账户、数据卷或外部项目。

本次报告为交付目录下的 `database-connectivity-v6.json`、`database-schema-v6.json`、`storage-http-v6.json`、`database-storage-v6.json`、`legacy-plan-save-v6.json` 以及完整前置检查报告。首轮记录单独保留。
