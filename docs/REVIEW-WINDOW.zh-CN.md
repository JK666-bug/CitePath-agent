建议给复核人 **两个半天 + 一个缓冲时段**，总计约 8 小时；不要一次做完。

## 每个窗口怎么做

1. 打开复核包：
   `outputs/CitePath-Formal-Evaluation-2026-11-13/human-review-packet/`
2. 填写自己的 `annotations/annotator-a.json`，不要看 `annotator-b.json`，也不要看机器提示。
3. 每 50 分钟休息 10 分钟；连续不超过 3 小时。
4. 拿不准的条目先留空，在缓冲窗口统一回看；不要靠猜。
5. 每完成一个窗口，记录完成数和遗留数（见下表）。

## 复核时的判断口径

- **选择题**：正确性、支持页、题目清晰、来源支持、答案键正确、不重复。
- **简答**：rubric 命中索引是 **从 0 开始**；5 点中 4 点通过，3 点不通过；同时判支持页和题目审计。
- **证据问答**：问题是否被讲义支持、答案是否正确、参考点覆盖、claim 是否完整、每条 claim 是否被有效引用页支持、是否有无关引用。
- 只使用原始 PDF 和题目记录；不要参考模型自评分。

## 完成后的命令

复核人填完 A 后，先跑单复核人描述性报告：

```powershell
cd backend
python tools/single_reviewer_report.py <observed-dataset.json> <annotator-a.json> <report.json> `
  --workflow <workflow-observations.json> `
  --approved-by "<批准人>" --approval-reference "<邮件/日期>" `
  --markdown <report.md>
```

`official_accepted` 仍为 `null`；`single_reviewer_conclusion` 给出单人结论。
