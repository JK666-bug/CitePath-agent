# 学习时长估算的校准作业

当前估时功能已实现并在真实前端展示，但它是透明的启发式，尚未用真实学习者的用时校准。模型生成题目的耗时、接口延迟或脚本自动答题耗时不能替代人的阅读与思考时间。本表保持空白，不能因此声称估时已校准。

## 当前规则

`backend/agent/planning_support.py:estimate_plan` 按章去重来源页，统计英文/数字单词和单个中日韩字符作为阅读单位；这不是模型计费 token。阅读速度由 profile 提供，默认 180 单位/分钟。

- 阅读：`max(来源页数, ceil(阅读单位/速度)+2×概念数, 1)` 分钟。
- 练习：`max(6×概念数, 6)` 分钟。
- 复习：`max(4×概念数, 4)` 分钟。
- 完成的任务保留历史估计；缺少正文或旧估计时显示限制。每日总预算用于容量提示，不能被描述为硬性保证完成。

## 有数据后的执行顺序

1. 统一任务开始、完成和暂停的记录口径，覆盖不同先修基础及任务类型；保存原始记录，不只留下完成快的样本。
2. 在调参前划分校准样本和独立验证样本，固定比较目标。分别报告平均绝对误差、误差中位数和高估/低估方向；未完成任务单独列出，不填零。
3. 只在校准样本上调整阅读速度假设或概念时间系数，在验证样本上比较旧、新规则。保存样本划分、参数、代码版本和缺失情况。
4. 若改善不稳定，保留原规则并显示不确定性。修改未来未完成任务的估时，不重写已完成任务或旧计划快照。

目前需要真人使用数据，不能由助手或模型代填。本作业属于估时增强验证，与正式评分/引用支持率的两人盲标是不同材料。
